# Fondamenti di Python

Le lezioni sono ordinate per difficoltà e possono essere svolte in sequenza.
Ogni script stampa esempi commentati e termina con un piccolo esercizio da
provare modificando il codice.

1. `01_tipi_di_dato.py` — numeri, booleani e conversioni.
2. `02_stringhe.py` — testo, metodi e slicing.
3. `03_liste.py` — raccolte ordinate e modificabili.
4. `04_tuple_e_insiemi.py` — dati immutabili e insiemi.
5. `05_dizionari.py` — associazioni chiave-valore.

Per eseguire una lezione dalla cartella principale:

```bash
python 01_fondamenti_python/01_tipi_di_dato.py
```
